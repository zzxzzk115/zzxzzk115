### Hi, I'm Kexuan Zhang (Lazy_V) 👋

I'm a PhD candidate at the **University of Leeds**, working on perceptual graphics, virtual reality, and high-performance rendering. I hold an MSc in High-Performance Graphics and Games Engineering and previously worked as a game server engineer at **Blackjack Studio** in Shanghai.

I also enjoy getting retro games and software running on handhelds.

[Portfolio](https://zzxzzk115.github.io/) · [Blog](https://zzxzzk115.github.io/blog/)
